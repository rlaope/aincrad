# ADR-0001: 결정론적 코어와 AI 정책 분리

- 상태: 승인됨
- 날짜: 2026-08-26

## 맥락

고정 HP·MP·스킬·아이템 규칙과 자율 AI 판단을 같은 계층에서 처리하면 모델이 게임 결과를 바꾸거나 동일 상황을 재현하지 못할 수 있습니다.

## 결정

중앙 도메인 엔진만 세계 상태를 변경합니다. AI 정책은 읽기 전용 `Perception`에서 허용된 `ActionIntent`를 선택합니다. 검증기는 행동 가능 여부와 비용을 확인하고, 리졸버가 사건을 생성합니다. 자연어 설명과 터미널 투영은 확정된 사건을 읽을 뿐 상태를 변경하지 않습니다.

## 결과

### 장점

- 규칙 불변식과 밸런스를 자동 테스트할 수 있습니다.
- 잘못된 모델 응답을 거부하고 안전 행동으로 대체할 수 있습니다.
- 기록된 행동열로 실행을 재생하고 디버깅할 수 있습니다.

### 비용

- 가능한 행동을 구조화된 스키마로 관리해야 합니다.
- 창발적인 자연어 제안을 즉시 세계 규칙으로 사용할 수 없습니다.
- 새 행동마다 검증과 사건 계약이 필요합니다.

## 재검토 조건

순수 규칙 코어가 프로파일링에서 실제 병목으로 확인되거나, 단일 프로세스로 목표 에이전트 수를 처리하지 못할 때 Rust 코어 또는 Actor 구조를 재검토합니다.
